# 电影布光拆解短片（竖版四层 · 逐层布光）

两种形式：
- **单镜头布光拆解**（第 1–10 节）：一个镜头 25–30 秒，四层逐层布光。
- **整段戏照明方案还原**（第 11–13 节）：整段原片（几分钟）+ 每个镜头一张 3D 静帧 + 整个棚的全景逐盏点灯。用户想看「整体方案 + 落到每个房间」时用这个。

给学导演、摄影、灯光的学生看：在 3D 还原的空间里，从全黑开始一道一道把光加上去，最后和原片对照，让人恍然大悟「原来光是这样来的」。**主角是光**；人物、家具只为真实感服务。

前提：已经有这场戏的 3D 场景（房子、灯位、机位），通常先用 `film-set-multicam` / `film-set-multicam-crew` / `film-set-longtake` 搭好，灯位来自摄影师公开的布光图或访谈。

## 1. 选题：一集一个镜头
- 一集只拆**一个镜头**（一个空间、一套光）。选光的结构最清楚、最有反直觉点的镜头（例：屋里一盏灯都没有，光全在窗外）。
- 做系列时，每集选**光的思路完全不同**的空间：硬光+烟的逆光剪影 / 柔光框+一块强色 / 同一房间换第二套光。结尾技术卡和前几集做对比（总功率、反差档数）。
- 和用户先对齐：选哪个镜头、竖版还是横版、单集还是系列。

## 2. 版式（1080×1920 竖版，从上到下）
| 层 | 内容 |
|---|---|
| 标题 | 「布光拆解 0N ｜ 空间 · 镜头号」+ 片名/摄影师 |
| ① 原片 | 先静帧；全部灯亮完后原速播一遍、再 0.5 倍速播一遍，**播完立刻结束** |
| ② 同景别 3D | 和原片**同一机位、同一焦段、同一景别**，逐层加光 |
| 状态条 | 「0 全黑 / 1 xx / 2 xx …」当前层高亮 |
| ③ 拍摄现场 | 同一套灯的俯视现场：能看见每盏灯具、柔光框、色纸、摄影机（青色机身+视锥），灯亮起时出标签 |
| ④ 技术披露 | 每层一张表 + 画面测光读数 |

参考坐标：标题 0–64，原片 64–516（1080×452），3D 524–976，状态条 980，现场 1026–1566（1080×540），技术 1572–1912。
字体用 PingFang SC：正文 Light、名称 Regular、标题 Medium；颜色柔和，不要大块黑底标签挡画面。

## 3. 节奏（总长 25–30 秒）
- 0–1 s：全黑 + 引子卡（例「屋里一盏灯都没有」）。
- **第 1 道光在第 2 秒「啪」地亮**：现场层用拉远的全景让这一组灯具**全部入画**（例：43 盏天光灯），一齐点亮 + 曝光闪一下 + 辉光 + 点灯音效；约 2.8 s 后推进到近景现场视角。
- 之后每层约 4.2 s，中层三拍：
  1. **之前**（0.3 s）
  2. **单独看这一层**（~1.4 s）：之前画面×0.2 压暗当底，叠上这一层新增的光×增益，角标写「单独看：xx 带来的光（亮度 ×N 显示）」；本来就烧白的窗口要遮掉
  3. **前后对比划屏**（~1.3 s）：左「加 xx 之前」/ 右「之后」
- 硬光灯（如 12K）随小一号音效一下打开；柔光、烟、反射光渐入。
- 对照段 2.5 s：原片静帧和 3D 之间划屏。
- 原片音频（台词）**只在最后播片时出现**；静帧上的烧录字幕用 inpaint 抹掉。

## 4. 叠光顺序：让每一步都看得见
- 先按布光逻辑排，再**量化检查**：每一步和上一步画面的平均绝对差，任何一步接近 0 就调顺序或合并（例：纱帘要在 T12 之前，T12 才显得出把纱帘打透；某个灯的光斑落在画外，就把它的地面反弹并进这一步）。
- 典型层：环境/天光 → 道具扩散体（窗帘、柔光框）→ 硬光主光 → 烟尘 → 反射光（没有补光灯）。
- 光束只在原片有烟尘的空间出现；原片漫射为主就不加雾，用柔光源表现。增强显著度可以，但在角标里写明放大倍数。

## 5. 渲染：每组灯单独出线性分层，合成里做叠加
Blender（EEVEE）里对**每个灯组 × 变体**各渲一张 32 位 EXR，转成 float16 npy：
- 视图：`mid`（原片机位，1280×536）、`set`（现场近景，1280×640）、`wide`（全景，只要第 1 层和全亮）
- 变体：窗帘有/无、烟有/无、GI（反射光）有/无；现场另渲一张 `AMB` 环境光底
- 现场视图：剖掉朝向相机的近墙和天花板（只对相机不可见，阴影保留）；灯具材质自发光；天光灯裙罩发光；隐藏这一镜不用的灯
- 用 `bpy.app.timers` 分帧跑渲染队列，写 `_PROG/_DONE/_ERR` 文件轮询（MCP 调用 60 s 会超时）

合成（numpy）：
- 线性空间按权重叠加各组，窗帘/烟/GI 系数做三线性插值 → ACES 色调映射 → sRGB
- 曝光校准：对最终全亮画面扫曝光值，让 10/25/50/75/90/97 百分位亮度最接近原片静帧
- 各组相对强度（`cal`）也可调，以贴近原片的明暗比例
- 烟尘的「亮雾」可在显示空间补一层大半径高斯光晕（screen 混合），强度为估算
- 现场图加轻度 bloom，叠渲染好的透明摄影机机身图层

## 6. EEVEE 的坑与补救（都要在技术卡里标「估算」）
- 屏幕空间 GI 看不到画外被照亮的院子/地面 → 窗外贴面光（院子反光）、地面光斑处放朝上面光（T12 落地反弹，反射率按 0.3）
- 相机直接看到的亮窗不够亮 → 窗外加只给相机看的发光板
- 体积雾：需要的密度往往比直觉大很多，先单独渲 T12+烟 的对比确认光束能显形

## 7. 人物与道具
- 用 Rodin（Hyper3D）按**姿势+服装**生成，不复刻演员长相。姿势写具体：「M4 抵肩、枪口举向前上方」「low ready 枪口指地」「黑色高顶战术头盔带侧轨」等。
- Rodin 贴图偏灰：材质乘深色（≈0.16）+ 去金属、粗糙度 0.7，剪影才像原片的一身黑。
- 朝向/枪口不对时：先把原片帧提亮 2 倍看清每个人；用「距离 + 相对机位方位角 + 朝向偏转 + 俯仰 + 镜像」摆位，镜像可以把枪换到另一侧；渲多版并排对照原片再定。
- 门、窗帘、床垫等按原片位置摆；画面里看不到的道具藏掉。
- 每次生成都花用户的额度：复用已生成模型；Rodin 设置是**按场景**的，生成时窗口场景要切到用户开了 Rodin 的那个场景；不要替用户填 API key。

## 8. 技术披露（④层）写什么
每层一张表，6 行左右：
- 灯具型号、数量 × 功率（以及**累计 kW**）、色温、色纸/附件（裙罩、挡板、柔光框）
- 位置（灯高、离人距离）、方向（方位角 0=北顺时针、俯角）
- 照度 lux 及相对曝光基准的档数（例 T2.8 · EI 800 · 1/48 s ≈118 lux = 0 档）
- 一句话说明这一层「做了什么」
- 底部实时测光：窗、帘、人脸、天花板等几个点的档数
- 开头卡写摄影机/镜头/曝光（查访谈，如 ARRI Alexa Open Gate + Master Prime）；每条区分「有出处」和「推算」
- 结尾卡：一致之处 + 局限（材质、烟的均匀性、推算的瞄准点等），诚实说明

## 9. 输出与编码
- 逐帧用 PIL 合成，管道喂给 ffmpeg（libx264 veryfast crf18，24000/1001）；每段控制在单次调用能跑完（工具命令 ≤180 s），分段后 concat
- 音频：合成点灯音效（继电器咔哒 + 低频冲击 + 钨丝灯嗡声 + 短混响），`adelay` 对齐到点灯时刻；原片音频 `adelay` 到播片时刻；`amix normalize=0`
- 抽 8–10 个时间点拼图自查：第 2 秒是否点亮、每层变化是否明显、人物朝向、结尾是否收在播片结束
- 不覆盖、不保存用户自己的 .blend；用 `bpy.data.libraries.write` 另存场景和 Rodin 资产

## 10. 来自用户反馈的要点（做之前先对照）
- 视觉重点是光：每个空间的照明方案差异要一眼看出（硬光束 vs 漫射 vs 色彩）
- 中层 3D 要和原片景别完全一致；现场层要看见所有光源
- 第一道光要「齐刷刷」全部露出来点亮才震撼，配音效
- 每层变化不明显就主动增强并标注，不要让观众猜
- 人物的头盔形状、材质、朝向、武器姿态都会被挑出来，逐一对照原片
- 节奏要快（~30 秒），播完原片就结束

## 11. 整段戏「照明方案还原」版式（社媒用 1080×1560）
| 层 | 高 | 内容 |
|---|---|---|
| 标题 | 56 | 左「《片名》开场突袭戏 · 照明方案还原」，右「摄影师：罗杰·迪金斯」——**两边同字体同字号** |
| 原片 | 452 | 整段原片 1080×452，带原声 |
| 信息条 | 44 | 「原片此刻：房间名」+「棚内 · 方案 A / 实景 · 纯自然光」 |
| 中层 3D | 640 | **原片每个镜头一张 3D 静帧，随原片硬切**（不推拉、不淡化） |
| 底层全景 | 358 | 整个棚俯拍：每盏灯、光束、「原片此刻」房间框（**浅绿底**，和灯标签的深色底区分） |

- 尺寸：用户要求不超过社媒尺寸（试过 1080×1452 → 最终 1080×1560）；**先问清最终尺寸再渲**。
- **渲染比例必须等于面板比例**：先按旧比例渲再裁切，中层只剩 62–71%、全景只剩 72–78%，用户会说「有画面信息没展示」。相机用 `sensor_fit='VERTICAL'`，改宽高比时上下视野不变、左右变宽。中层 1296×768，全景 1296×430。
- 时长按用户要求截断（例：5:40 之后删掉），结尾原声 `afade` 1.5 s。

### 中层：每个镜头一张，站在原片摄影机身后看
- 每个镜头单独一个视角：眼睛放在原片机位后方约 1.6 m、上方 3.4 m（不高于吊顶灯区），看向机位前方 3 m，焦距 14 mm。画面里放黄色摄影机 + 视锥（`set_frustum` / `place_rig`）。
- **不要整个房间共用一个俯拍机位**：只有小摄影机挪位置，观众会觉得「没跟着分镜走」。验收：在每个切点抽帧，3D 画面的帧差都要明显（>3）。
- 每个镜头用自己的人物站位（staging）、卡车位置、方案 A/B、墙洞、爆炸烟。
- 实景镜头同样每个一张：外景地模型 + 只有太阳 + 摄影机视锥，标「实景 · 纯自然光 · 一盏灯都没有」。车内镜头机位离得更近。
- 左下角写「镜头 N · 房间 · 站在这个镜头的摄影机身后看（黄色 = 摄影机和视锥）」。

### 中层顶部：灯具参数条（等同摄影还原里放大「景别 / 焦距」）
- 最左一格是方案和合计功率（大号「202 kW 合计」）；之后每种灯一格：灯名、大号数量「43 盏 × 2K」、「= 86 kW」。
- 当前房间的主光那一格加金框 +「本镜主光」。
- 三行要留够高度（≈126 px）：先抽帧检查有没有文字被切或重叠。

### 底层全景：一盏一盏点亮
- 每盏灯渲一层（不开室内反射），合成里按时间叠加：天光灯按排蛇形扫，约 0.12 s 一盏；T12 一盏一盏重重亮；再亮 Blonde。每盏亮时冲高再回落，灯头加一团辉光，每盏配一声「咔」（T12 用大音效）。
- 说明文字放全景**左下角小字幕 + 计数**（「天光灯 29 / 43」），**不要放画面中央挡灯**。
- 灯全部亮完后，淡入「带室内反射」的完整层，并配一句「屋里的反射光」。
- 换第二套光：原有的灯保持亮着，新增的灯一盏盏补亮，撤掉的灯熄灭，观众能看出改了什么。
- 开头「棚里还没开灯」：用细字体（Light）配深灰圆角底，不要粗字加描边。

## 12. 让 3D 的光「像原片」：踩过的坑
- **房间发黑、不像天亮** → EEVEE 默认没有屋内的多次反射光。必须放体积光照探针（`LightProbe` VOLUME，覆盖整栋房子，分辨率约 48×22×7，3 次反弹），**每套布光状态先烘焙一次**（`bpy.ops.object.lightprobe_cache_bake`，需要 `temp_override(window, scene, view_layer)`）再渲。烘焙后所有房间亮透，暗部有层次。
- **光比太小，看不出是太阳** → 屋里补光压低，T12 加强，太阳色偏暖（×(1.08, 1.0, 0.80)）。原片室内实测 R:G:B ≈ 1.3:1.2:1。
- 证明「这是太阳」的两个教学段：同一张图收 4 档光圈（只剩阳光照到的地方亮）、伪色曝光（红 = 比中灰亮 4 档以上）。都在合成里算，不用重渲。
- **光斑像射灯**（圆斑） → T12 光束角放宽到 55°，让地上的光斑由窗洞形状决定。
- **窗外的光束进不了屋** → 窗玻璃、纱帘都关掉 `visible_shadow`；屋内的光柱另建「灯 → 窗洞」的凸包体积，用体积自发光表现（EEVEE 屋内体积受光太弱）。
- **全景里看不到光束** → 灯具光束用「灯 → 窗洞」锥体 + 体积发光（强度随距离衰减），天光灯只给一圈淡光锥。
- **中层和全景的同一个房间一亮一暗** → 两边的灯组增益必须一致（曾经中层把 Blonde 压到 35%，北面房间就黑了）。
- **户外太阳灯没关**：棚内渲染一律关掉 `lt_SUN`，否则整个棚发灰。
- **外景渲染后忘了恢复集合**：外景函数会隐藏 KEY_Set / KEY_Beams，导致纱帘、窗外补光、光束全部消失。在棚内 setup 里**每次都显式打开**需要的集合，不要依赖上一次的状态。
- 在房间视角里放体积光束会糊成一层脏雾：房间视角不放光束，光束留给全景。
- 同机位直接对照原片会暴露机位、人物的细小误差。要做的话只挑 3–4 个关键镜头精校。
- 线性分层合成（每组灯一层 npy）能在不重渲的情况下调光比、色温、曝光，也能做逐组点灯。

## 13. 流程与稳定性
- 防闪烁：**不要逐帧渲 3D 漫游**（样本少 + 屏幕空间 GI 随相机变化 → 光一直闪；100 盏灯一帧 2–3 s，全片要十几个小时）。改用高质量静帧 + 合成，抽帧量亮度波动（<1/255）。
- 长任务：Blender 里用 `bpy.app.timers` 队列，每步写 `_PROG/_DONE/_ERR`；Blender 渲染时会卡住 MCP 调用（80 s 超时属正常），改在设备 shell 里轮询进度文件。
- 渲染完把 Blender 窗口场景切回用户的 `Scene`。
- Blender 断开时先请用户在 BlenderMCP 面板点 Start MCP Server；空场景用 `restore_all.restore()` 重建。
- 设备 shell 单次 ≤180 s：视频分 40 段，4 段并行一批；heredoc 太长会报 E2BIG，长脚本先在云端写文件再 `device_commit_files`。
- 交付前抽 10–12 个时间点拼成一张图自查：标题、参数条是否被切、切点是否跟分镜、点灯计数、伪色/收光圈段落。
- 人名用标准译名（Roger Deakins = 罗杰·迪金斯），用户写法可疑时照标准写并告知。
